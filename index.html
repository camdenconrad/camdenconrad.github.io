05 / HOW I BUILD

Principles

Determinism

Owned clocks and pure functions: identical inputs produce byte-identical output, so behavior is reproducible and regression-testable.

Bounded & explicit

No unbounded recursion or hidden allocation on hot paths. Bounds you can point to — the Power-of-Ten influence.

Verified

Deterministic test harnesses and bit-for-bit replays. Regression tests target the known sources of numerical and timing drift.

From scratch

I build the critical piece myself when it buys control, testability, or understanding — the renderer, the clock, the protocol.

Fault-aware

Written as if a bit flipped somewhere: explicit state, defined failure modes, no undefined behavior swept under the rug.
